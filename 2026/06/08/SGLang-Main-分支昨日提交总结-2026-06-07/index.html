概述

本文对 SGLang main 分支在 UTC+8 2026年6月7日 00:00 至 24:00 期间的提交进行了总结和分类。
昨日共计提交约 29 个 commit，重点涵盖了多模态扩散模型优化、DeepSeek V4 适配增强、Radix Cache 算法改进以及推理稳定性提升。

1. 新模型支持与增强

昨日主要增加了对 Ideogram4 和 Cosmos3 等多模态扩散模型的支持与优化。

commit message 总结 PR 链接

2. 性能优化

性能优化重点集中在 Radix Cache 匹配效率提升、扩散模型预计算以及推理路径重构。

commit message 总结 PR 链接

4. 参数与环境变量变更

昨日主要引入了用于稳定性和推理优化的环境变量。

新增环境变量

  • SGLANG_EAGER_INPUT_NO_COPY: 用于控制 eager 模式前向路径是否绕过 CUDA Graph 缓冲区的显存拷贝。
  • SGLANG_ENABLE_ASYNC_ASSERT: 启用异步断言不变性检查（如 NaN, OOB 等），默认为 False，在 CI 中默认开启。

Server 参数变动

昨日代码中未检测到 server_args.py 的 CLI 参数直接新增，但对投机采样的参数处理逻辑进行了内部重构（如 spec_utils 整合）。
