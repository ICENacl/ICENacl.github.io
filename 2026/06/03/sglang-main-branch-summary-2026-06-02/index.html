server_args.py 新增参数

  • load_snapshot_publish_interval: 快照发布间隔 (默认 15)
  • radix_cache_backend: 自定义 Radix Cache 后端工厂名称
  • dsa_prefill_backend: DSA 预填充后端 (替代 NSA)
  • dsa_decode_backend: DSA 解码后端 (替代 NSA)
  • dsa_topk_backend: DSA TopK 后端 (可选 sgl-kernel, torch, flashinfer)
  • deepep_dispatcher_output_dtype: DeepEP 调度器输出数据类型 (auto, bf16, fp8, int8, nvfp4)
  • lmcache_config_file: LMCache 配置文件路径
  • enable_deepseek_v4_fp4_indexer: 启用 DeepSeek V4 的 FP4 索引器
  • disable_attn_tp_gather: 禁用注意力机制中的 TP Gather 操作
  • kv_canary: 启用 KV-Canary 测试功能
  • kv_canary_real_data: KV-Canary 真实数据配置
  • kv_canary_sweep_interval: KV-Canary 扫描间隔
  • enable_dsa_prefill_context_parallel: 启用 DSA 预填充的上下文并行
  • dsa_prefill_cp_mode: DSA 预填充 CP 模式 (round-robin-split 等)
  • optimistic_prefill_retries: 乐观预填充的重试次数
  • asr_max_buffer_seconds: ASR 最大缓冲区秒数
  • asr_max_concurrent_sessions: ASR 最大并发会话数

新增加的环境变量

  • SGLANG_GEMMA_OUT_OF_PLACE_POSITION_MUTATION
  • SGLANG_PHASE_CHECKER_DEBUG
  • SGLANG_SIMULATE_UNIFORM_EXPERTS / SGLANG_SIMULATE_ROUND_ROBIN_EXPERTS
  • SGLANG_PP_SKIP_PURE_CHUNKED_OUTPUT_COMM
  • SGLANG_KILLPG_ON_SCHEDULER_EXCEPTION
  • SGLANG_RAY_BUNDLE_INDICES: Ray Custom PG 模式的 bundle 索引
  • SGLANG_HICACHE_NIXL_USE_DIRECT_IO: HiCache NIXL 后端是否使用 Direct IO
  • SGLANG_ENABLE_FAILED_SESSION_PROBE: 启用失败会话探测
  • SGLANG_FLASHINFER_NVFP4_PER_TOKEN_ACTIVATION: 启用 FlashInfer TRT-LLM MoE 的 NVFP4 逐 Token 激活缩放
  • SGLANG_DSA_*: 一系列 DSA 相关的环境变量 (由 NSA 重命名)
  • SGLANG_OPT_DPSK_V4_*: DeepSeek V4 的各种优化开关 (Radix, Compressor, Fused kernels 等)
  • SGLANG_ENABLE_EMBED_REPLICATION: 启用嵌入层副本，避免 All-Reduce
  • SGLANG_ENCODER_*: EPD (Encoder Prefill Disaggregation) 相关的超时、并发和 GPU 使用配置
  • SGLANG_KV_CANARY_*: KV-Canary 测试套件的相关变量
