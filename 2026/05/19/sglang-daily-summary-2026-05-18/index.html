1. Scheduler Refactoring (Major)

The day’s most significant change is a massive refactoring of the Scheduler class. The monolithic scheduler.py and its mixins have been decomposed into modular, single-responsibility components under scheduler_components/. This improves maintainability, testability, and code organization.

Key Takeaways

  1. Scheduler Refactoring is the dominant change today — the monolithic Scheduler class has been decomposed into 15+ focused components under scheduler_components/, significantly improving code maintainability.
  2. New Models: KIMI-K2.5 with MXFP4 on AMD, Qwen3.5 on Intel XPU.
  3. MoE Performance: DeepGEMM BF16 for DeepEP LL, Triton autotune for DeepSeekV4, flashinfer_cutedsl migration to MoeRunner.
  4. DeepEP Dispatcher now supports configurable output dtype via --deepep-dispatcher-output-dtype, replacing the deprecated env vars DEEP_NORMAL_MODE_USE_INT8_QUANT and SGLANG_DEEPEP_BF16_DISPATCH.
  5. Disaggregation: MiMoV2 gains EPD disaggregation support; fake KV backend gets conclude_state; upstream cancellation feature added to SMG.
  6. Bug Fixes: 8 fixes across diffusion, NPU, AMX, EPLB, disaggregation, and diffusion LoRA.
