Overview

Yesterday’s commits were predominantly focused on VLM (Vision-Language Model) performance optimization, AMD DeepSeek V4 runtime fixes, and observability improvements. No new model architectures were introduced.

VLM Performance Optimization (6 commits)

The majority of yesterday’s work concentrated on optimizing multimodal inference, particularly for Qwen-VL models. Key improvements include reducing CUDA IPC staging overhead, batching small H2D transfers, simplifying rope indexing for image-only requests, and accepting precomputed multimodal metadata to avoid redundant computation.

Commit Message Summary PR Link
[VLM] avoid extra cuda-ipc staging for preprocessed input (#26096) Eliminates unnecessary CUDA IPC staging when inputs are already preprocessed, reducing latency. #26096
[VLM] feat: replace small H2D calls with a single one for qwen-vl (#26167) Batches multiple small host-to-device transfers into a single call for Qwen-VL, improving transfer efficiency. #26167
[VLM] adopt simplified get_rope_index for image-only requests (#26100) Uses a simplified rope index computation path when processing image-only requests, avoiding unnecessary overhead. #26100
[VLM] accept precomputed multimodal metadata (#26101) Allows callers to pass precomputed multimodal metadata, avoiding redundant recomputation in the processor pipeline. #26101
[srt] store req input ids as arrays (#26165) Changes request input ID storage from individual values to arrays for more efficient batching and memory layout. #26165
[diffusion] Clean up VSA attention hot path (#25514) Cleans up the Video Sparse Attention hot path in diffusion models for better code clarity and potential performance. #25514
