三、新功能：KV-Canary 系统

KV-Canary 是一套面向生产环境的 KV Cache 一致性校验与故障注入框架，昨日通过 19 个 commit 完整落地。核心能力包括：

  • 数据层与 MHA KV-Pool Patcher：对 MHA、SWA、DeepSeek-V4 等注意力池进行补丁化封装；
  • JIT Kernel 体系：实现了 verify、write、plan 三套 CUDA JIT kernel，并附带 reference implementation；
  • Token Oracle：确定性 token 采样器，用于生成可复现的请求标识与预期输出；
  • Perturb 故障注入：支持对 req-to-token、real-KV（used/unused/post-forward）、next-token-swap 等维度注入随机扰动；
  • 健康检查与统计：周期性全 radix-tree sweep、SWA 发散报告、kernel-run-counter 健康检查；
  • EAGLE & PD-Disaggregation 兼容： speculative decoding 与 PD 分离场景均已覆盖。
