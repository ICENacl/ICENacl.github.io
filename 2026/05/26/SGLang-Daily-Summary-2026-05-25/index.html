SGLang main 分支每日 Commit 总结 (2026-05-25)

日期: 2026-05-25 (UTC+8)
Commit 总数: 39

一、整体概览

昨日 main 分支共合入 39 个 commit，主要涵盖以下几个方面：

  • 实验性 Rust Router (sgl-router): 大量新增代码，包含完整的 HTTP Router 实现、KV Events 订阅策略、K8s 服务发现、端到端测试等，是昨日最大的改动模块
  • Diffusion 模块: CFG gating 缓存优化、NVFP4 默认后端切换、NPU disaggregation 支持、VAE channels_last_策略
  • 性能优化: EAGLE draft softmax 跳过、Qwen3.5 topkGatingSoftmax 新增 case、CPU KV-cache 写入加速、VLM precomputed input ids 复用
  • Bug 修复: FlashInfer allreduce fusion、HiCache lru_cache 突变列表、EAGLE v2 metadata 初始化顺序、DSv4 multi-step draft、GDN XPU 正确性等
  • server_args.py: 新增 --disable-attn-tp-gather 参数
  • 环境变量: 新增 SGLANG_DIFFUSION_CFG_GATE_STEP

二、重点模块详细总结

2.1 实验性 Rust Router (sgl-router)

三、总结

昨日 SGLang 的改动以 实验性 Rust Router 的引入 和 Diffusion 模块增强 为主要亮点。Router 项目涵盖了从服务发现到负载均衡、从健康检查到端到端测试的完整实现，为 SGLang 的多 worker 部署提供了原生高性能路由方案。Diffusion 方面，CFG gating 和 NVFP4 后端切换显著提升了推理效率。此外，多项 speculative decoding 和 VLM 性能优化也值得关注。
