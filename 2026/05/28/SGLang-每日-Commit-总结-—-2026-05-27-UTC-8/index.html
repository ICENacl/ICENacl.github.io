八、关键改动总结

重点关注

  1. 新增模型:

    • Ling_2_6: 基于 BailingMoeV2_5 架构的新模型，支持 Mamba cache + extra_buffer
    • Cosmos3: 新的视频生成扩散模型，完整 pipeline 支持
    • NemotronH V3 Omni: WeightsMapper + NanoNemotronVL 模型
    • Qwen3-vl / Qwen3-omni (CPU): CPU AMX 后端支持

  2. 性能优化:

    • Overlap 调度 WAR barrier，无额外前向开销
    • EAGLE topk=1 时跳过全词汇表 softmax
    • PP 纯 chunked prefill 跳过 output 通信

  3. 重要 Bug Fix:

    • flashinfer_cutlass MoE 16 字节对齐崩溃修复
    • PD prefill top logprobs 崩溃修复
    • PD 跨 rank 队列分歧修复

  4. server_args.py 新增参数:

    • --asr-max-buffer-seconds（默认 60）
    • --asr-max-concurrent-sessions（默认 32）
    • --lmcache-config-file
    • amx_attn 作为 mm_attention_backend 新选项

  5. 新增环境变量:

    • SGLANG_PP_SKIP_PURE_CHUNKED_OUTPUT_COMM
    • SGLANG_ENABLE_ASYNC_ASSERT（统一替代旧的 NAN_DETECTION 和 OOB_DETECTION）
    • SGLANG_OPT_USE_TRITON_FUSED_MHC
